Game overview

What is Flambeur?

  • A poker roguelike in the browser, set in a smoky Paris casino.
  • You start with $20 and a debt to Le Patron. Your bankroll is your life and your shop money.
  • Rip booster packs to build a tiny deck. Cards carry finishes, stamps and traits.
  • Duel 10 rivals across 12 rounds. Bust them, or bust out.
  • Why: poker roguelikes are all solo. I wanted one where the bluff is real: a live rival across the table.
THE DUEL: your hand at the bottom, the rival across the table
FLAMBEUR02
Rules

How a round plays

Appraisal = Value × Hype × 2Grade

1 · Lock in

You're dealt 8 cards. Discard if you want, then lock 1–5 as a poker hand. Both seats lock blind.

2 · Bet on yourself

Min or Max. Win a Max and the House pays you; lose it and the rival takes it. The underdog bets second.

3 · Showdown

Higher Appraisal takes the hand. Best of 3 hands wins the round and the pot.

Win · lose · difficulty

Win: bust every rival, survive 12 rounds and pay off Le Patron's marker. Lose: your bankroll hits $0. Rivals come in Easy, Medium and High Roller.

Controls

Mouse: click cards to pick them, click the ticket buttons (Play, Flamber, Min, Max). Hover anything to see what it does. Space skips an animation, M mutes.

FLAMBEUR03
Core mechanics

What makes it different

🔥 Flamber

Merge a locked hand into one stronger card, TFT style: ★1 → ★3. Each hand type leaves a trait, and traits stack into bonus hands. Leftovers turn to Ash, so the deck never shrinks.

The Tabac

Between rounds: booster packs, collectibles that boost Hype (order matters), scratchers, and a grading desk that ships a card off for a round.

Tables & bosses

4 Tables × 3 rounds. A new rival each Table with their own deck build; every 3rd round is a boss with a twist.

FLAMBEUR05
State machine

The match is a phase machine

  • 6 phases: draft · deal · bet · spoils · shop · over. Reveal and settle are automatic steps between them.
  • Every move goes through step(match, seat, action). It checks the action is legal, applies it, then advance() moves phases until a player owes a move.
  • A match is a seed + an action log, so any game can be replayed exactly.

FLAMBEUR07
Built multiplayer-first

Play real people, live

  • Real-time 1v1 duels: share a room code with a friend, or hit quick match to get paired with whoever's online.
  • The server runs the game. Your browser sends moves, the server runs the same step() and sends each player only what they're allowed to see.
  • No cheating by peeking: the rival's hand never reaches your browser, so devtools can't show it.
  • Every move is saved before it's sent, so a crashed server rebuilds every live match by replaying its log.
FLAMBEUR08
Daily seed & what's next

Same deal for everyone

📅 The Daily

One seed a day, the same shuffle, packs and rival for every player in the world. Easy, Medium or High Roller.

It runs on the server, so nobody can sim the seed offline and submit a perfect run.

🏆 Global leaderboard

Two boards each day: best score (replay as much as you want) and first try (no do-overs).

Fair by design: today's seed is locked behind a hash, and yesterday's seed is published so anyone can replay it.

✨ Coming soon: cosmetics

Card backs, table felts and more, unlocked by playing, never bought.

Next on the list after that: a 10-player battle royale. The engine already seats 10.

Code · the core loop

One way in: step()

SRC/ENGINE/MATCH.TS
// the only way a match changes. works on a copy, so a throw can't leave it half-changed
export function step(match: Match, s: SeatId, action: Action): StepResult {
  return stepInPlace(JSON.parse(JSON.stringify(match)), s, action)
}

export function stepInPlace(m: Match, s: SeatId, action: Action): StepResult {
  const why = problem(m, s, action)   // is this move legal for this seat, right now?
  if (why) throw new Error(`seat ${s} ${action.type}: ${why}`)  // fail loud
  const emit: Emit = []                  // events the UI animates: deals, chips, count-ups
  apply(m, s, action, emit)              // do the move
  m.n++                                  // one more action in the log
  advance(m, emit)                      // run the phase machine forward
  check(m)                               // invariants: throws on any impossible state
  return { match: m, events: emit }
}

// keeps moving the match forward while nobody owes a move in this phase
function advance(m: Match, emit: Emit): void {
  for (;;) {
    if (m.phase === 'over' || pending(m).length > 0) return
    if (m.phase === 'draft' || m.phase === 'shop') enterRound(m, emit)  // shuffle, deal 8
    else if (m.phase === 'deal') afterLocks(m, emit)    // open betting, or reveal
    else if (m.phase === 'bet') revealHand(m, emit)    // score it, next hand or settle
    else if (m.phase === 'spoils') nextShop(m, emit)   // round + 1, into the tabac
  }
}

  hype = (hype + s.hype) * s.xhype

FLAMBEUR13
Limitations & challenges

What was hard

Limitations

  • Some newer sprites are still flat placeholders while their final art gets drawn.
  • Solo dev, one week: cosmetics and the battle royale didn't make the cut yet.
  • Balance isn't finished: the High Roller difficulty is still a wall.

Challenges

  • Balancing by hand doesn't scale. I wrote a sim that plays 1000s of runs with different bots to tune the economy.
  • A full rules rewrite mid-week (v2: best of 3, Flamber as a hand) after the first playtest.
  • Teaching a deep game fast: a seeded first run and La Fée Verte, a guide who explains each mechanic as it shows up.
